# Holberton Révision

Un site de révision indépendant, créé pour retrouver facilement les notions étudiées à Holberton. Les fiches, exemples et schémas sont rédigés pour aider à comprendre, sans être une publication officielle de l'école.

**🌐 [Accéder au site](https://revision-hbtn.soleiljaune.be)**

## Sur le site

- **Fiches et cours** : des résumés courts et des explications détaillées, classés par thème.
- **Recherche et sommaire** : retrouver rapidement une notion, puis lire le cours correspondant.
- **Exemples et schémas** : visualiser le fonctionnement des commandes et du code.
- **Favoris** : conserver ses fiches préférées sur l'appareil utilisé.

**Aucun compte n’est nécessaire** pour consulter les cours et utiliser les quiz invités. Les favoris et les résultats des quiz restent enregistrés dans le navigateur. Le quiz charge des fichiers JavaScript et JSON complémentaires : **le téléchargement de `index.html` seul ne garantit pas le fonctionnement hors ligne**.

Les spécifications techniques et les évolutions envisagées sont suivies séparément dans [le cahier des charges](docs/COMPTES_OPTIONNELS_ET_QUIZ.md).

## Participer
