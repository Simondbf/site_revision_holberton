À propos de ce support

Un support de révision librement consultable, sans compte.

Origine des fiches

Les notions sont synthétisées à partir des cours, exercices et échanges Holberton déjà travaillés. Ce site est une initiative pédagogique indépendante et ne constitue pas une documentation officielle de l’école.

Fonctionnement hors ligne

Télécharge le fichier index.html ou décompresse l’archive du site, puis ouvre index.html dans ton navigateur. Les fiches et la recherche restent disponibles sans Internet.

Recherche

La barre de recherche permet de retrouver les mots-clés à travers les titres, les définitions et les thèmes.

Favoris et affichage

Marque une notion avec l’étoile pour la retrouver ici. Les liens de cours sont partageables ; le thème et les favoris restent propres à ce navigateur.

Un site de révision collaboratif

Les cours sont accessibles sans compte. Toute personne peut suggérer une correction, compléter une explication ou proposer un schéma en passant par GitHub. Les changements sont examinés avant publication.

Tu veux contribuer ? Consulte le code source ou propose une amélioration. Les consignes de contribution figurent dans le dépôt.

Informations sur le site

Édition et publication : projet Holberton Révision, maintenu par le responsable du dépôt Simondbf. Contact par le suivi GitHub.

Hébergement : site hébergé sur un serveur VPS chez Hetzner Online GmbH (Allemagne). Les coordonnées légales complètes de l'éditeur restent à compléter avant de considérer cette rubrique comme des mentions légales définitives.

Données locales : les favoris et le choix du thème sont conservés dans ton navigateur (stockage local). Aucune création de compte n'est requise aujourd'hui. Le serveur d'hébergement peut conserver des journaux techniques : cette rubrique ne prétend pas décrire une politique complète de confidentialité.

Code source : consultable publiquement sur GitHub. Les conditions de réutilisation du code sont à définir explicitement dans le dépôt avant toute déclaration de licence.
